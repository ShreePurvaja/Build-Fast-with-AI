Data Fetching & Native `np.nan` Handling

When predictions are requested by account_id, the engine queries the platform database to construct signal vectors automatically.

📈 Linear Regression Slope Calculation for `EngagementTrend`

If an employee has completed at least 4 closed survey cycles over the past 12 months, the engine computes the trend slope \(m\):

$$m = \frac{n\sum (xy) - (\sum x)(\sum y)}{n\sum (x^2) - (\sum x)^2}$$

Where \(x\) is the survey cycle index \((0, 1, 2, ...)\) and \(y\) is the cycle engagement score. If fewer than 4 surveys exist, `EngagementTrend` is set to np.nan.

⚡ Native `np.nan` Missing Value Strategy

When 4 or more signals exist, any missing null fields are passed natively to XGBoost as np.nan.

  • No Synthetic Averages: The engine does NOT replace missing data with artificial dataset averages.
  • XGBoost Default Branches: Tree split nodes process np.nan values natively by following learned default missing branches.
  • Insufficient Data Cutoff: If fewer than 4 signals are present, scoring halts and risk_tier = "insufficient_data" is returned.

SHAP Explanation Math ($\Delta_{pp}$ Conversion)

Standard SHAP TreeExplainer outputs feature contributions in log-odds (margin space). The Trainery engine converts log-odds into clear Probability Percentage Points ($\Delta_{pp}$) for HR leaders.

Step 1: Base Probability
$$P_{\text{base}} = \frac{1}{1 + e^{-\phi_0}}$$

Where \(\phi_0\) is the dataset log-odds baseline.

Step 2: Probability with Feature
$$P_{\text{with}} = \frac{1}{1 + e^{-(\phi_0 + \phi_i)}}$$

Where \(\phi_i\) is raw SHAP feature margin.

Step 3: Contribution ($\Delta_{pp}$)
$$\Delta_{pp} = (P_{\text{with}} - P_{\text{base}}) \times 100$$

Expressed directly in percentage points.

⚠️ Safeguard Rule: Any missing signal passed as np.nan gets stamped with is_imputed = true. Missing signals are strictly filtered out and banned from appearing in the employee's Top Risk Drivers or Top Protective Factors lists!

Risk Percentages ($Resign\%$) & Risk Tiers

Uncalibrated decision trees push raw probabilities toward binary extremes ($0\%$ or $100\%$). Model C uses Isotonic Regression Calibration (CalibratedClassifierCV) to map raw outputs into smooth empirical probabilities.

Probability Clipping Rule

$$\text{resign\_prob} = \text{clip}(P(\text{calibrated}), 0.05, 0.95)$$

Minimum predicted risk is capped at 5.0% and maximum risk at 95.0%.
